ytmtui

A YouTube Music TUI in Rust. This is the unofficial pacman repository.

Add the repo

[ytmtui]
SigLevel = Optional TrustAll
Server = https://bell09.github.io/ytmtui/$arch

Install

sudo pacman -Sy ytmtui
sudo pacman -Syu   # future updates

Packages are unsigned, hence TrustAll. Source and other install options are on GitHub.

Repository database: x86_64/ytmtui.db
